# 正向能量島與正向詞語戳泡泡

適合台灣國小四年級的英語互動遊戲，支援電子白板、電腦與平板。

## 遊戲檔案

- `index.html`：正向能量島，包含三關九題、即時回饋、得分，通關後可玩戳泡泡。
- `bubbles.html`：獨立的 30 秒正向詞語戳泡泡，不需要先闖三關。

## 使用方法

下載後以瀏覽器開啟任一 HTML 檔即可遊玩。所有程式、樣式與音效均內建，不需要安裝套件或連接網路。兩個檔案放在相同資料夾，可保留首頁的泡泡下載連結。

## 活動內容

正向能量島練習情境選擇、成長型思維、認識情緒與尋求協助。選項只顯示英文，情境與回饋提供中文輔助。

戳泡泡有不規則落下的正面與負面語句。戳中正面泡泡收集 +1，戳中負面泡泡或漏接不扣分。遊戲結束後顯示收集清單，可重玩。音效預設關閉，可自行開啟。

所有情緒都值得被聽見。遊戲分數獎勵學習與嘗試，不是在評分孩子的心情。

## GitHub Pages

若要在 GitHub Pages 提供線上遊玩，可將這些檔案放到儲存庫根目錄，並在 Settings → Pages 選擇從 `main` 分支的根目錄發布。首頁為 `index.html`，獨立泡泡遊戲位於 `bubbles.html`。

遊戲不蒐集學生個人資料，成績只存在當次瀏覽器頁面，重玩或重新整理後會重設。
